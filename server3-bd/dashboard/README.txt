La interfaz de usuario construida en Angular

	+ src/app/services/api.service.ts: Clases en typescript encargadas de hacer las peticiones HTTP a tu API de gestion para traer o enviar datos.

	+ src/app/pages/gestion/: Componentes de interfaz con formularios reactivos para registrar usuarios (incluyendo un modulo para subir sus fotos iniciales), crear grupos escolares y asignar horarios.

	+ src/app/pages/asistencia/: Una vista con una tabla dinamica que muestre los registros de asistencia con indicadores de colores (verde para a tiempo, amarillo para retardo, rojo para ausencia) y 
	  filtros por filtros por fecha/materia.

	+ src/app/pages/emociones/: Vistas que integren una libreria de graficas (como Chart.js o ECharts) para mostrar tendencias emocionales semanales y la distribucion general del dia mediante graficas de
	  barras y lineas.
